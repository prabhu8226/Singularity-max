    Model status — what is computed vs assumed

      Ideal-equilibrium core validated against NASA CEA2022 (see the Verification tab). Everything downstream is a first-generation engineering model: Bartz accuracy is typically ±20–30 %, bell angles are typical-range values (not MOC-optimised), c* efficiency is an assumption, kinetic loss is computed only for H₂/O₂ and CH₄/O₂, and film/ablative/radiation-only cooling, injector spray physics, structures, and 2-D/CFD flow are not yet included. Conceptual sizing only — not for flight-hardware sign-off.
